# GC2 Inventory Demos

Inventory ships demo content as importable Unity packages.

| Package | Focus |
|---------|--------|
| **Inventory.Adventure** | Adventure-style loot, bags, and exploration |
| **Inventory.Examples** | General inventory visual scripting patterns |
| **Inventory.Items** | Item definition and property examples |
| **Inventory.UI** | Bag, merchant, and tinker UI setups |

Import via the Game Creator installer, open demo scenes, and cross-reference [Visual Scripting](../visual-scripting/triggers.md) catalogs.
