# Conditions

Core **Conditions** evaluate true/false checks for branching in Triggers, Actions, and dedicated **Conditions** components.

Categories include Characters, Input, Physics, Variables, Storage, Audio, and more.

{% hint style="info" %}
**Status:** Catalog in progress. Core ships ~100 conditions — contributors should add categories as collapsible sections matching the Unity picker.
{% endhint %}

Official reference: [Conditions](https://docs.gamecreator.io/gamecreator/visual-scripting/conditions/)
