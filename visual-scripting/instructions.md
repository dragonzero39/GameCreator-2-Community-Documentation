# Instructions

Core **Instructions** run inside **Actions** components. They are organized in the Unity picker by category (Characters, Cameras, Audio, Variables, etc.).

This page will catalog all Core instructions grouped by category. See [Triggers](triggers.md) for events and [Conditions](conditions.md) for branch checks.

{% hint style="info" %}
**Status:** Catalog in progress. Core ships ~345 instructions — contributors should add categories as collapsible sections matching the Unity picker.
{% endhint %}

Official reference: [Actions — Instructions](https://docs.gamecreator.io/gamecreator/visual-scripting/actions/instructions/)
