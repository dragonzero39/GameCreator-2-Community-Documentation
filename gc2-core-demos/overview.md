# GC2 Core Demos

Core ships demo content as importable **Unity packages** (not embedded scenes in the plugin folder). Install them from the Game Creator installer or module Examples folder.

## Available demo packages

| Package | Focus |
|---------|--------|
| **GameCreator.Examples** | General Core visual scripting and interaction patterns |
| **GameCreator.Characters** | Character controller, animation, navigation, combat basics |
| **GameCreator.Blockout** | Greybox level layout with a playable character and camera |

## How to use demos

1. Open your Unity project with GC2 Core installed.
2. Use **Game Creator → Installer** (or import the `.unitypackage` from the Core Examples folder).
3. Open the imported demo scene and press Play.
4. Select objects with **Trigger**, **Actions**, or **Conditions** components to study wiring.
5. Cross-reference node names with [Visual Scripting](../visual-scripting/triggers.md) pages.
