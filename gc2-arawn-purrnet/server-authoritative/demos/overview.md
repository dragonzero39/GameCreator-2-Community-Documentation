# Demos — Server Authoritative

Document dedicated-server demo scenes, containerized runs, and cloud deploy test setups once verified locally.

## Typical starting point (to expand)

1. Run a **dedicated server** build (or headless Editor/server mode if your stack supports it).
2. Connect one or more **clients** to the published address/port.
3. Verify authority: server-side simulation, client prediction/interpolation as configured.
4. Optional: deploy the same server image to a host such as [Edgegap](https://docs.edgegap.com/unity) and reconnect clients to the deployment endpoint.
