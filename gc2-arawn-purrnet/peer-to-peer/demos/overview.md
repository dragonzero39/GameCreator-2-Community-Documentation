# Demos — Peer to Peer

Document PurrNet demo scenes, wizard outputs, and local multiplayer test setups here once verified locally.

## Typical starting point

1. Run the **PurrNet Scene Setup Wizard**.
2. Press Play with **two instances** (Editor + build, or twin Editors) for host/join testing.
3. Confirm one instance hosts and the second joins; verify character spawn and module replication you enabled.
