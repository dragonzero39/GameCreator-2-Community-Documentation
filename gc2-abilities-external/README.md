# GC2 Abilities (External)

{% hint style="danger" %}
**Third-party plugin.** Abilities is **not** part of official Game Creator 2 from Catsoft Studios. This space documents community knowledge only. Licensing, support, and updates come from the Abilities author — not Game Creator.
{% endhint %}

---

## What this space is for

The **Abilities** plugin extends Game Creator 2 with ability-slot style gameplay (cooldowns, ability bars, modular ability definitions — exact feature set depends on the third-party asset version).

This community space will mirror the **same four-section layout** as official GC2 modules once contributors with a licensed copy document it:

| Section | Purpose |
|---------|---------|
| **Core Functionality** | Ability assets, slots, cooldowns, UI |
| **GC2 Abilities Demos** | Example scenes from the asset |
| **Code** | Extension APIs (author-provided) |
| **Visual Scripting** | Triggers, Instructions, Conditions |

---

## Documentation status

**Not started.** Contributors who own the Abilities asset should:

2. Follow [DOCUMENTATION-STRUCTURE.md](../DOCUMENTATION-STRUCTURE.md) and [CONTRIBUTING.md](../CONTRIBUTING.md).
